RX400h专用Android实时仪表；当前约3Hz目标，自动连接、侧视车图重连、后台采集、返回退出。本机设置内选择OBD设备；不再记录/保存/恢复行车日志，不再有稳健策略或性能监视模块。

本地测试候选，不是已完成实车验证的正式版本。APK、历史原始数据和精确构建映射需另备份；源码归档不能代替整个旧电脑的备份。恢复开发前请阅读上面的归档说明。
